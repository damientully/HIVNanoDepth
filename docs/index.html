Optimising Nanopore Sequencing for Reliable HIV-1 Drug Resistance Profiling

Application-specific sequencing-depth requirements for HIV-1 drug resistance genotyping.

Daniel Bugembe Lule · Deogratius Ssemwanga · Nicholas Bbosa · Pontiano Kaleebu · Damien C. Tully

Oxford Nanopore HIV-1 protease & RT 68 participants, Uganda Matched Sanger comparison

This repository contains the analysis code and figure-generation scripts behind the manuscript. Using matched Sanger and Oxford Nanopore sequencing and systematic in-silico read subsampling (0.5–40% of reads), the study shows that the optimal sequencing depth depends on the intended analytical application. Clinical drug-resistance interpretation reached complete concordance with full-depth data from only 5% of retained reads with no false-positive calls, whereas within-host diversity and quantitative variant analyses required substantially greater depth.

2Quick start

Install the Python dependencies, then run any figure script — paths resolve relative to each script, so no editing is required:

pip install -r requirements.txt

python3 Figure2/make_combined_ABC.py
python3 Figure3/make_subtype_confusion_gd.py
python3 Figure4/make_subsampling_fidelity_figure.py
python3 Figure6/make_resistance_concordance_figure.py
python3 SFigure2/make_discordance_predictors_fig.py

# Figure 1 (R)
cd Figure1 && Rscript sequencing_depth_viral_load_error_figure.R

Each script writes a 600 dpi .png and a vector .pdf into its folder. Set OUT_DIR (or --out-dir) to redirect outputs, and DATA_DIR to point at inputs held elsewhere.

3Reproducibility notes

  • Figures 4–6 ship the intermediate tables the plotting scripts consume; the upstream scripts that rebuild them from raw BAM/VCF/Stanford outputs are included for transparency and take their input directories as command-line arguments.
  • Figure5/variant_vaf_comparison.csv is produced by plot_variant_counts_comparison.py from per-sample VCFs and is not committed; generate it (or supply --input) before running plot_vaf_agreement.py.
  • Figure2/ccc_stats.json was reconstructed from the published Lin's CCC (0.839; 95% CI 0.733–0.928) and Pearson r (0.839).
